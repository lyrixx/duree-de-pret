# Court ou long ?

Faut-il emprunter sur la durée la plus courte possible ou la plus longue possible pour acheter un
logement en France ? Cette étude compare les deux options chiffres à l'appui.

En ligne : https://lyrixx.github.io/duree-de-pret/

## Contenu

- La mécanique d'un prêt amortissable : intérêts, assurance, grille de taux par durée.
- Les facteurs qui font pencher la balance : taux, assurance, capacité d'emprunt, rendement des
  placements, fiscalité, inflation, revente, renégociation, etc.
- Des cas d'étude chiffrés, avec les taux d'octobre 2026.
- L'argument « avec un prêt long, on a plus d'argent à soi et on peut le placer », testé avec un
  placement à 8 % par an et une simulation de Monte-Carlo.
- Un simulateur à curseurs pour tester son propre cas.
- La méthodologie, un test de robustesse et les sources (34 références, officielles en priorité).

Ce n'est pas un conseil financier personnalisé.

## Utilisation

Tout tient dans `index.html` : ouvrez-le dans un navigateur. Seuls les polices (Google Fonts) et
Chart.js (cdnjs) sont chargés depuis Internet. Tous les calculs se font dans le navigateur.

Chaque push sur `main` déploie la page sur GitHub Pages
(`.github/workflows/pages.yml`).
